FAQ

Questions fréquentes

Mes données sont-elles envoyées à un serveur ?

Non, sauf pour l'onglet PDF si vous envoyez un fichier : il faut alors l'héberger pour que le QR code puisse l'ouvrir. Pour tous les autres types, le QR code est entièrement généré dans votre navigateur, et le contenu saisi ainsi que le logo choisi ne sont ni transmis ni conservés par Facilo.

Comment faire un QR code qui ouvre un PDF ?

Un QR code contient un lien, pas le fichier lui-même. Dans l'onglet PDF, collez le lien d'un PDF déjà en ligne, ou envoyez votre fichier : Facilo l'héberge et génère le lien pour vous. Au scan, le téléphone ouvre le PDF. Si vous remplacez le fichier plus tard, gardez la même adresse pour que le QR code déjà imprimé continue de fonctionner.

PNG ou SVG : lequel choisir ?

Le PNG convient pour le web, les réseaux sociaux et les documents. Le SVG est un format vectoriel : il reste parfaitement net à toutes les tailles, idéal pour une affiche, un flyer ou une impression grand format.

Comment saisir un numéro WhatsApp ?

Saisissez l'indicatif du pays suivi du numéro, sans le « + » et sans le « 0 » initial. Par exemple, le 06 12 34 56 78 en France devient 33612345678. Le scan ouvre directement une conversation WhatsApp avec ce numéro.

Le QR code Wi-Fi fonctionne-t-il avec tous les téléphones ?

La plupart des smartphones récents (iOS et Android) reconnaissent automatiquement ce format et proposent de rejoindre le réseau en un scan. Les caractères spéciaux du nom ou du mot de passe sont gérés automatiquement.

Puis-je changer les couleurs ou ajouter un logo sans risquer de casser le QR code ?

Oui, tant que le contraste entre le motif et le fond reste suffisant : gardez un motif foncé sur un fond clair. Avec un logo, le niveau de correction maximal est appliqué automatiquement, et le logo reste petit au centre. Testez toujours votre QR code avec un téléphone avant de l'imprimer.

Y a-t-il une limite de caractères ?

Un QR code peut contenir jusqu'à quelques milliers de caractères, mais plus le contenu est long, plus le motif est dense et difficile à scanner. Privilégiez des contenus courts, comme un lien. Le logo et un niveau de correction élevé réduisent aussi la capacité.
